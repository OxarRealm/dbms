# 吕金鸣 - 实验工作内容

## 总体工作说明

本项目是一个基于C++和Qt开发的通用数据库管理系统（DBMS），实现了完整的数据库管理功能，包括表结构管理、数据操作、SQL查询、索引管理、查询优化等核心功能。系统采用自定义文件存储格式（.dbf和.dat文件），支持多种索引技术（相邻索引、哈希索引、B+树索引）和智能索引建议系统。

## 个人工作内容

我负责项目的后续功能开发、系统完善、文档编写和最终汇报工作，在已有核心功能基础上，重点实现用户权限管理和智能索引推荐系统增强功能，并负责团队协调和最终汇报。

### 1. 用户权限管理系统实现

设计并实现完整的用户权限管理功能，包括用户管理（CREATE USER、ALTER USER、DROP USER）、角色管理（CREATE ROLE、GRANT ROLE、REVOKE ROLE）和权限管理（GRANT、REVOKE）。实现用户认证机制（使用MD5或SHA256密码加密存储）、会话管理和权限检查中间件，确保所有数据库操作（DDL、DML、查询）都有权限验证。开发GUI界面支持用户、角色和权限的可视化管理，提供友好的权限配置界面。

### 2. 智能索引推荐系统增强

在基础索引建议系统基础上，增强推荐算法，实现多字段索引推荐、索引选择性分析、查询模式识别（等值查询、范围查询、排序查询）和索引成本分析（考虑索引维护成本）。开发完整的索引管理GUI界面，包括索引列表显示、创建索引对话框、索引统计信息展示和推荐结果可视化。实现SQL接口支持CREATE INDEX、DROP INDEX和SHOW INDEXES语句。使用Qt Charts实现查询性能趋势图、字段使用频率柱状图、慢查询分析图表和索引效果对比图等可视化展示。

### 3. 索引管理界面和SQL接口

实现Index Management标签页，支持索引的创建、查看、删除和统计。扩展SQL解析器支持索引相关语句的解析和执行。集成相邻索引、哈希索引和B+树索引（计划中）到统一的索引管理界面，提供索引性能统计和优化建议。

### 4. 系统测试与优化

完善系统测试，编写用户权限管理和索引推荐系统的测试用例，分析系统优势和局限性，进行性能优化。确保系统稳定性和可靠性，提升用户体验。

### 5. 实验报告编写与最终汇报

完善项目实验报告，详细记录系统设计思路、实现过程、技术选型和测试结果。整理项目文档，确保文档完整性和准确性。制作项目演示PPT，包括项目概述、系统架构、核心功能演示、数据库新技术展示和系统优势分析。准备汇报稿，清晰讲解系统功能、技术实现和创新点。负责最终的项目汇报和答辩工作，展示团队协作成果。

## 技术运用

- **编程语言**：C++（C++14标准）
- **GUI框架**：Qt 5.15.2（Qt Charts用于数据可视化）
- **加密算法**：MD5或SHA256（密码加密存储）
- **设计模式**：中间件模式（权限检查）、观察者模式（索引推荐）、单例模式（权限管理器）
- **数据结构**：权限表、角色表、索引统计表、哈希表（权限缓存）
- **算法**：权限继承算法、索引推荐算法优化、可视化算法、性能分析算法
