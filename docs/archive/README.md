## 归档原则

以下类型的文档会被归档：
1. **已完成的功能实现进度文档** - 功能实现完成后，进度文档不再需要频繁更新
2. **已完成的问题分析和修复总结** - 问题解决后，分析文档保留作为参考
3. **已完成的测试分析文档** - 测试完成后，分析文档保留作为参考
