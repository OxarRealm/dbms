## 🎯 后续工作清单

### 一、重点任务（老师要求做精）⭐

#### 1.1 用户权限管理系统 ⭐⭐⭐⭐⭐（最高优先级）

**目标**：实现完整的用户权限管理功能，包括用户认证、角色管理、权限控制等。

**功能需求**：
1. **用户管理**
   - CREATE USER - 创建用户（用户名、密码）
   - ALTER USER - 修改用户（修改密码、启用/禁用）
   - DROP USER - 删除用户
   - 用户信息存储（.usr文件或系统表）

2. **角色管理**
   - CREATE ROLE - 创建角色
   - GRANT ROLE - 授予角色
   - REVOKE ROLE - 撤销角色
   - DROP ROLE - 删除角色

3. **权限管理**
   - GRANT - 授予权限
     - 表级权限：SELECT, INSERT, UPDATE, DELETE, ALTER, DROP
     - 数据库级权限：CREATE TABLE, DROP DATABASE
     - 系统权限：CREATE USER, GRANT OPTION
   - REVOKE - 撤销权限
   - 权限继承（角色权限）

4. **权限检查**
   - 所有DDL操作前检查权限
   - 所有DML操作前检查权限
   - 所有查询操作前检查权限
   - 权限不足时返回错误信息

5. **用户认证**
   - 登录验证（用户名、密码）
   - 会话管理（当前登录用户）
   - 密码加密存储（MD5或SHA256）

6. **GUI界面**
   - 用户管理界面（用户列表、创建、编辑、删除）
   - 角色管理界面（角色列表、创建、编辑、删除）
   - 权限管理界面（权限授予、撤销、查看）
   - 登录界面（启动时或切换用户）

**技术实现**：
- 用户信息存储：创建系统表`_users`和`_roles`，或使用.usr文件
- 权限表结构：`_permissions`表（用户ID、对象类型、对象名、权限类型）
- 权限检查中间件：在QueryExecutor、DDLExecutor、DMLExecutor中添加权限检查
- 密码加密：使用C++的crypto库或Qt的QCryptographicHash

**工作量估算**：10-15天

**优先级**：⭐⭐⭐⭐⭐（最高）
